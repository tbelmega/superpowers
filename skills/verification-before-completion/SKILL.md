# Verification Before Completion

Evidence before claims.

## Iron Law

`NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE`

## Gate

- Identify the command that proves the claim.
- Run the command that proves the claim in this message.
- Read the output and exit status.
- Report the actual result, not the hoped-for one.

## Apply Before

- Saying tests, builds, lint, or fixes pass
- Claiming a requirement is complete
- Moving to the next task
- Committing, opening a PR, or reporting success from delegated work

If you have not run fresh verification, say that plainly instead of implying success.
